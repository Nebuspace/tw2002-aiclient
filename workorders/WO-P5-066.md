## Design decisions (hub-ratified 2026-07-27T00:00:08Z)

**1. The standing band spells `T)rigger`; the STOP banner keeps `T)assign`.**
Canon carries the triad in two registers and spells the `T` token differently in each:
the calm standing hint band is `^A)ode  A)nalyze  R)ecord  T)rigger  L)chains  P panic`
(`mode-line-and-teach-controls.md:136`, `visual-language.md:302`); the banner's promoted
teach line is `A)nalyze  R)ecord  T)assign` (`:146`, `:271`). 066 owns the standing band,
so it must NOT reuse `stopbanner.TEACH_LINE` — doing so would ship the banner's spelling
into the calm band while still passing any check that merely looks for the letters A, R
and T. `TEACH_LINE` is untouched by this WO. Pinned in both directions
(`test_band_uses_trigger_not_the_banner_s_assign`, and a canon-grounding test asserting
BOTH spellings appear verbatim in canon so neither is this repo's invention).

**2. A/R/T triad only.** Canon's band has six tokens; `^A)ode` is the Mode chord
(ADR-002 / WO-P5-061-ENTRY) and `L)chains` / `P panic` are the N5 operate-the-app cluster
(WO-071). This WO emits the triad and nothing else; `TEACH_TOKENS` is a tuple precisely so
the later WOs extend a sequence rather than re-parse a flat string. Pinned by
`test_band_does_not_carry_other_wos_tokens`, which guards scope creep in both directions.

**3. The band right-aligns against LIVENESS's left edge, not the row's.**
Canon's diagram (`:219`) hugs the row's right edge, but that diagram contains no liveness
cluster — the operationally load-bearing "is it frozen?" signal that `control_seat`'s own
docstring pins as keeping its full space ahead of every chip. Canon's *reading order*
(chips left, band right, band yields the strip's centre to the TX channel, `:229-231`) is
preserved exactly; the one element canon does not model keeps the priority the product
already proved it needs. Recorded as a canon-vs-as-built divergence rather than silently
resolved. Pinned by `test_liveness_survives_every_width_the_band_renders_at`.

**4. All-or-nothing, never truncated.** Same rule as the ARM/CONN chips: a clipped
`T)rig` is not a shorter true statement, it is a token the reader cannot resolve. The band
is the lowest-priority element on the row (pure affordance chrome, zero live state), so it
is the correct first thing to lose under width pressure.

**5. Chrome tone, never a badge.** Canon: the band is "right-aligned in **cyan**
(`accent_attr`), the chrome accent — affordance chrome, not data" (`:229-231`). It
resolves to `_chrome_attr` and deliberately skips the `A_BOLD | A_REVERSE` badge path,
because reverse-video is canon's one "selected/active" signal (`:179-181`) and badging
three unwired labels would make them shout louder than the ARM chip's real state.

## Proof

**Layer-A** — `tests/test_cockpit_teachband.py`, 29 cases: canon wording (both registers,
each grounded verbatim in canon), scope, ASCII no-swap, placement, ≥1 blank column each
side, width invariance across widths 1–200, all-or-nothing degradation, byte-identical
narrow-row equivalence to the pre-066 row, segments-join-equals-line, chrome tone distinct
from every badge tone, and hostile-input honest-absence.

**Layer-B** — `tests/test_cockpit_teachband_pty.py`, 4 cases: real curses in a 40×160 pty,
pyte replay. Rendered control-strip row as captured:
```
║APP  ARM ?  DISC?                    …                    A)nalyze  R)ecord  T)rigger ○ ⠋ → -║
                                                           ^ band cols 124-151, liveness intact at the right edge
```

**Mutation-proof (the pins were broken on purpose and watched go red, then restored
byte-identical):**

| mutation | pin that caught it |
|---|---|
| `T)rigger` → `T)assign` | `test_band_uses_trigger_not_the_banner_s_assign` (+2 others) |
| all-or-nothing → truncate | `test_band_drops_whole_never_truncated` |
| `TEACH_TONE` → `"ok"` | `test_chrome_tone_is_distinct_from_every_badge_tone` |
| bind `ord("A")` in the handler | `test_teach_keys_are_not_bound_in_the_cockpit_handler` |
| unwire the band from `screens.py` | all 4 Layer-B pty cases |

The last two matter most: Accept #2 ("no live execution behind labels") is enforced
mechanically rather than by promise — the day a wire lands without its own WO, the pin goes
red first. And the Layer-B mutation proves the pty assertions can actually fail, rather than
passing because `find_text` is lenient.
